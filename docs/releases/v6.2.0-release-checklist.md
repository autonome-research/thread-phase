- Clean `npm ci --ignore-scripts`, build and workspace typechecks on Node 24.15.0 / npm 11.12.1.
- 730 tests pass: core 568, agents 121, CLI 41. Command: `npm run test --workspaces --if-present -- --testTimeout=15000`. The longer timeout accommodates the previously known SQLite stress-test timing issue; no test or assertion is skipped.
- Exact packed core/agents/CLI install together; imports and CLI help work without the optional TypeSafe SDK.
- Packed TypeSafe consumer type checks cover ESM/CJS SDK clients and the routing example.
- Compared packed core declarations against published v6.1.0: only `dist/typesafe.d.ts` added, no existing declaration changed or removed.
- Production audits of the source lockfile and clean packed install report zero vulnerabilities.
- No new paid TypeSafe calls during release preparation. The earlier live routing smoke succeeded with `jev-1.13.0`.
- The existing Node >=22.5 runtime requirement is unchanged; this release validation ran on Node 24.15.0, not a fresh minimum-runtime matrix.
