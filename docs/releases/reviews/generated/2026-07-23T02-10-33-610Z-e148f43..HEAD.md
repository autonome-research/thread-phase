## 3. Best-practice improvements

- `packages/thread-phase/src/session/job-runner.ts`: consider strengthening `reconcileAbandoned()` pagination. If all first-page candidates recover before finalization, `transitioned === 0` stops processing even if later pages still contain stale jobs.
- Ensure CI covers every Node version claimed by `engines`; the release checklist explicitly skips Node 23–25.
