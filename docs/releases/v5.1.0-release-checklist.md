## Final review remediation

The first full-range release review reported one critical lifecycle finding and two best-practice findings. All were repaired and tested:

- [x] Cancellation-request append failures are retained and surfaced while atomic `CANCELLED` finalization is still attempted.
- [x] Simultaneous cancellation-request persistence and drain failures have deterministic aggregation order.
- [x] Per-item trace IDs reject C1 as well as C0 Unicode control characters before dispatch.
- [x] Every `AgentEventPersistenceFailure` field is readonly in the public declaration.
- [x] Rejection of `FAILED` terminal persistence retains pipeline/heartbeat primacy and appends drain and persistence failures deterministically.
- [x] Rejected `COMPLETED` persistence falls back to a durable `FAILED` transition when available.
- [x] Stability documentation distinguishes bounded same-database process coordination from distributed orchestration.
- [x] Failure observers can await reentrant `flush()` or `close()` after asynchronous boundaries without self-deadlock.
- [x] Heartbeat timeout documentation explicitly records that `heartbeatTimeoutMs` requires `heartbeatMs`.
- [x] Observer-local reentrant close barriers remain separate from the canonical external close barrier.
- [x] Event-bus dispatch snapshots subscriptions so callback-time mutations affect only later events.
- [x] Four-process fresh-database initialization passed, plus ten focused race repetitions.
- [x] Optional `refreshHeartbeat()` provides v5.1 owner-observable refresh without strengthening published-v5 `enableHeartbeat()` boolean semantics.
- [x] A transition-only published-v5 store passed repeated automatic heartbeat intervals through the legacy fallback.
- [x] Pre-registration option/context setup failures retain their original rejection, do not invoke ownership acquisition, leave jobs PENDING, and release local context/job registrations.
- [x] `JobRunner.start()` returns an aborted setup-failure handle whose result observes the original rejection without an orphaned promise.
- [x] `AgentEventHandlerFailure` is readonly and frozen before observers receive it.
- [x] Cancellation requested by `finalResult()` or the caller signal remains authoritative before completion intent.
- [x] Context restoration setter failures cannot replace the authoritative pipeline/cancellation result.
